# النشر وحل المشكلات

## التاريخ

تطبيق معالجة مجموعات نصوص محلية وإدارتها. يستخدم العرض نصوصاً مولدة فقط.

## البيئة المحلية

استخدم Python 3.12 للفحوص المسجلة. صدّر قيم .env.example إلى العملية؛ يحل config.py المسارات النسبية من جذر التطبيق. اضبط SECRET_KEY ثابتاً للجلسات وENABLE_TELEGRAM=0. يطلب bootstrap_demo.py كلمة مدير جديدة بطول 12 ويكتب النص المولد إذا لم يكن موجوداً فقط. Cython اختياري يحتاج مترجماً؛ Python هو المسار الافتراضي المفحوص.

## تشخيص الأعطال

ابدأ بالتأكد من إصدار اللغة والامتدادات وتثبيت القفل، ثم اتصال قاعدة البيانات وترتيب مخططها ومتغيرات العملية. افحص عنوان API من الجهاز الفعلي لا عنوان localhost الخاص بجهاز آخر. شغل PHP للمسارات الديناميكية والموجه المحلي المرفق حيث يوجد؛ لا ينفذ خادم ثابت ملفات PHP. أبق تحقق TLS فعالاً، ولا تعالج فشل المزود بإظهار نجاح. لا تعِد إرسال نتائج غير مؤكدة دون مراجعة. في Windows أوقف العملية التي تستخدم مخرجات البناء أو محرك Prisma قبل الاستعادة.

لم يُفحص تطابق Cython وعمال Linux والتعافي من وظيفة منقطعة. القياس المرفق خاص بـPython على جهاز Windows الموثق وليس مقارنة تسريع. إدخال Telegram الاختياري معطل في العرض.

حذف مفتاح من الشيفرة لا يلغيه عند المزود. يجب تدوير بيانات النشر القديمة بشكل مستقل؛ لم يُثبت تدويرها في هذا العمل.
