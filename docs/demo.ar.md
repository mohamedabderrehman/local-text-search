# العرض الاصطناعي

ينشئ المستخدم بحثاً بعد الدخول ← يمسح العامل المجموعة الاصطناعية ← تُحدَّث الوظيفة والنتائج ← يتصفح المالك أو ينزل النتائج ← تراجع الإدارة الاستخدام.

## التهيئة

استخدم Python 3.12 للفحوص المسجلة. صدّر قيم .env.example إلى العملية؛ يحل config.py المسارات النسبية من جذر التطبيق. اضبط SECRET_KEY ثابتاً للجلسات وENABLE_TELEGRAM=0. يطلب bootstrap_demo.py كلمة مدير جديدة بطول 12 ويكتب النص المولد إذا لم يكن موجوداً فقط. Cython اختياري يحتاج مترجماً؛ Python هو المسار الافتراضي المفحوص.

## سير العرض

- مسح نصوص عبر mmap وتنفيذ Python بديل
- تسريع Cython اختياري
- تقدم الوظائف وكتابة دفعات النتائج إلى ملفات
- صفحات نتائج وتنزيل وفحص ملكية
- إدارة مستخدمين وإحصاءات استخدام
- إدخال Telegram اختياري معطل افتراضياً

## الفحوص المنفذة

نجحت اختبارات Python الستة: الأسطر الطويلة ومطابقة AND وعدم وجود نتائج والبايتات المختلطة وحد نتائج مشترك بين الملفات وملكية الوظيفة ورفض البحث دون دخول وفحص تراجع على ألف سطر. وجد قياس Windows دون Cython 800 نتيجة في 800 ألف سطر مولد بحجم 36,353,960 بايت؛ الأوقات 10.2452 و10.9746 و10.5983 ثانية دون تفريغ مخبأ النظام.

## الحدود

لم يُفحص تطابق Cython وعمال Linux والتعافي من وظيفة منقطعة. القياس المرفق خاص بـPython على جهاز Windows الموثق وليس مقارنة تسريع. إدخال Telegram الاختياري معطل في العرض.

التقط الواجهات من التطبيق الفعلي ببيانات تجريبية. الصور ليست دليل نشر إنتاجي، ولا يمثل نص العرض تسجيل فيديو. توجد أوامر التنفيذ في setup.ar.md.
