## إبقاء بحث المتن الطويل خارج طلب الويب

يقدم Flask واجهة المستخدم والإدارة بينما تمسح وظائف خلفية ملفات mmap. تحفظ SQLite بيانات الوظيفة وتحتفظ ملفات نتائج مجمعة بالمطابقات، وتستعلم الواجهة عن التقدم قبل عرض الصفحات أو التنزيل. تُفحص ملكية النتائج عند حدود التطبيق.

يعتمد سلوك العمال على المنصة. يستخدم مسار Windows الموثق الخيوط ويشكل matcher Cython الاختياري مسار بناء مستقلاً. يتحكم مصدر إعداد واحد الآن في مسارات المتن والقاعدة والنتائج والجلسات، فلا يتعارض إعداد المتن مع قيمة ثابتة بمحرك البحث.

## مشاركة حد النتائج بين العمال

قد يؤدي منح كل عامل ملفات حداً مستقلاً إلى نتائج أكثر مما طلب المستخدم. يستخدم الإصدار ميزانية نتائج مشتركة ويفحص الأسطر الطويلة والبايتات المختلطة وتعدد الملفات. تغطي ستة اختبارات هذه الحالات وحدود المستخدمين؛ تبقى الوظائف المنقطعة وتطابق التسريع للتحقق اللاحق.

يستخدم القياس 800 ألف سطر مولد ويوثق الحجم والمطابقات وعتاد Windows وإصدار Python وثلاثة أوقات فعلية. لم يُفرغ مخبأ النظام ولم يُفعل Cython. تجعل هذه التفاصيل القياس قابلاً للتكرار دون ادعاء تسريع غير مقاس أو معالجة إنتاجية بحجم تيرابايت.
